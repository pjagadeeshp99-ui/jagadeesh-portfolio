# Jagadeesh P. — IT Portfolio Website

A responsive, static portfolio website for Jagadeesh P., IT Security and Network Engineer.

## Folder structure

```text
jagadeesh-portfolio/
├── index.html
├── styles.css
├── script.js
├── README.md
└── .nojekyll
```

## Run locally

1. Extract the ZIP file.
2. Open `index.html` in a modern browser.

For a local development server, open this folder in VS Code and use the Live Server extension, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Sign in to GitHub and create a new public repository, for example `jagadeesh-portfolio`.
2. Extract the ZIP and upload the contents of the `jagadeesh-portfolio` folder to the repository root. Ensure `index.html`, `styles.css`, and `script.js` are at the root level.
3. Commit the files to the `main` branch.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for the Pages deployment to finish. Your site will be available at `https://YOUR-GITHUB-USERNAME.github.io/jagadeesh-portfolio/`.

If you use a repository named `YOUR-GITHUB-USERNAME.github.io`, the site will be published at `https://YOUR-GITHUB-USERNAME.github.io/`.

## Customization

- Edit content in `index.html`.
- Edit colors, layout and responsive breakpoints in `styles.css`.
- Edit navigation and reveal interactions in `script.js`.
